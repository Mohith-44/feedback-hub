#Feedback - Hub

Build a modern Feedback Collection web application.

Features:

- Responsive UI

- Home page

- Feedback Form

- Name

- Email

- Rating (1–5 stars)

- Category dropdown

- Comments textbox

- Submit button

- Success message after submission

Admin Dashboard:

- View all feedback

- Search feedback

- Filter by rating

- Delete feedback

- Dashboard cards showing:

  - Total Feedback

  - Average Rating

Use a modern professional design with Tailwind CSS.
